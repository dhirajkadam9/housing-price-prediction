# Housing Price Prediction

## About
I built a machine learning model to predict house prices 
in Indian cities using Linear Regression.

## Tools Used
- Python
- Pandas
- Scikit-Learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## What I Did
- Analyzed housing data across multiple Indian cities
- Performed Exploratory Data Analysis (EDA)
- Built Linear Regression model for price prediction
- Evaluated model using R2 Score and RMSE

## Key Findings
- Identified most and least expensive cities
- Found features that affect house price the most
- Garage presence significantly impacts house price
- Analyzed impact of area, bedrooms, and distance on price

- `Housing price data.csv` - Dataset
